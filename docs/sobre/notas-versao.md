# Notas de versão

## 1.0.0 — 27 de agosto de 2026

Primeira versão estável do Py-RPAutom.

### Recursos

- Automação de navegadores com recursos para navegação, interação com
  elementos, esperas, janelas, capturas e requisições HTTP.
- Automação de aplicações desktop do Windows por meio do `pywinauto`, com
  suporte aos backends `win32` e `uia`.
- Utilitários para arquivos, pastas, planilhas, PDFs, compactação, processos,
  terminal, logs, configurações e conversão para Base64.

### Documentação

- Guia explicativo para cada um dos módulos públicos.
- Referência completa das funções públicas, integrada às respectivas
  docstrings.
- Demonstração de uma automação web completa na página inicial.
- Modos claro e escuro, com realce de sintaxe próprio para cada paleta.

### Estabilidade

- API pública considerada estável a partir desta versão.
- Classificação do projeto alterada de beta para estável.
