# python_utils

Utilitários de sistema: arquivos e pastas, planilhas, PDF, processos,
variáveis de ambiente, log e data/hora. É o módulo que sustenta os
outros dois — automações web e desktop quase sempre precisam ler uma
entrada e gravar um resultado.

Para exemplos de uso passo a passo, veja o
[guia de utilitários python](../guia_usuario/python_utils.md).
